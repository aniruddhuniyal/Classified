# index

> A classified index of my projects.

This repository is used to **classify, organize, and keep track of my projects** across different domains.

Rather than containing the projects themselves, `index` acts as a showroom for organizing the things I build.

## Categories

Projects are classified into areas such as:

* **Systems** — dotfiles, low-level software, etc.
* **Engineering** — CAD, simulation, automotive, aerospace, and related projects.
* **Developer Tools** — Utilities and development tools.
* **Applications** — General-purpose software and desktop applications.
* **Experimental** — Prototypes, concepts, experiments, and projects that don't fit elsewhere.

## Project Index

Each project is assigned a primary category based on its main purpose.

Some projects may overlap multiple domains, but the classification system keeps the overall collection organized and easy to navigate.
